# TTS 스피커 — PC 프로그램

늘 켜 두는 PC에서 **브라우저 없이** 가족 메시지를 읽어 주는 프로그램이에요.
오른쪽 아래 트레이(^)에 숨어서 듣고 있다가, 메시지가 오면 **딩동 → 소리 내어 읽기 → 알림 창 [알겠어요 👍]**.

웹 스피커와 똑같이 움직여서, 가족 휴대폰은 **지금 쓰는 웹 주소 그대로** 보내면 돼요.
보낸 쪽에는 **보냄 → 🔊 말함 → 👍 확인** 이 그대로 보이고, 📢 전체로 보내도 같이 받아요.

## 설치 (아들 PC)

1. `TTS스피커.exe` 를 USB로 옮겨서 바탕 화면이나 `문서` 같은 곳에 둬요 (설치 과정 없음).
2. 두 번 누르면 창이 떠요. (처음에 "Windows의 PC 보호" 가 뜨면 **추가 정보 → 실행**)
3. **이 스피커 이름** 에 `아들 방` 처럼 적어요.
4. 가족 휴대폰으로 화면의 **QR** 을 찍어요 (한 번만 찍으면 계속 연결돼요).
   QR이 안 되면 휴대폰 웹앱 → 메시지 보내기 → **코드로 연결** 에 6자리 숫자.
5. **🔊 소리** 탭에서 **시험 듣기** 로 소리 확인 → **✓ 완료 — 트레이로**.

PC를 다시 켜면 저절로 트레이에서 시작해요 (💻 PC 탭 → *PC 시작 시 자동 실행*).

## 꼭 확인할 것

- **절전**: 💻 PC 탭의 *절전 막기* 가 켜져 있으면 프로그램이 도는 동안 PC가 잠들지 않아요 (화면은 꺼져도 됨).
  노트북 덮개를 닫으면 잠들 수 있어요 → 설정 → 시스템 → 전원 → 덮개 닫을 때 *아무것도 안 함*.
- **소리**: PC 스피커 볼륨을 켜 두세요. 헤드셋을 꽂아 두는 PC라면 🔊 소리 탭 → **소리 나올 곳** 에서
  *항상 이 스피커로* 를 골라 두면 Windows 기본 장치가 바뀌어도 거기로 나와요.
- **한국어 목소리**: 없다고 나오면 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 ⋯ → 언어 옵션 → *음성* 설치.

## 트레이 메뉴

설정 열기 · 연결 QR 보기 · 1시간 쉬기 · 시험 듣기 · 최근 메시지 · 종료

## 소리 설정

- 목소리 (이 PC의 한국어 목소리: 보통 *해미*), 소리 크기, 빠르기, 높낮이, 반복 1~3번
- **보낸 사람 목소리 따르기**: 휴대폰에서 고른 *내 목소리* (👨 남자 / 👩 여자 / 이름) 를 따라요.
  이 PC에 남자 한국어 목소리가 없으면 같은 목소리를 낮게 해서 구분해요.
- 보낸 사람 이름도 읽기 (기본 끔 — 알림 창엔 늘 보여요), 딩동 소리, 조용한 시간 (소리 없이 알림 창만)
- **인터넷 고품질 목소리** (기본 끔): Microsoft 온라인 음성(선희·인준·현수)으로 읽어요.
  읽을 말이 Microsoft 서비스로 가요. 안 되면 이 PC 목소리로 읽어요.

## 알아 둘 점

- 메시지는 무료 공개 중계 서버 [ntfy.sh](https://ntfy.sh)를 거쳐요. 민감한 내용은 보내지 마세요.
- 꺼져 있던 동안 10분 넘게 지난 메시지는 읽지 않고 *최근 메시지* 에 ‘놓침’으로만 남겨요 (12시간까지).
- 기록·설정: `%LOCALAPPDATA%\TTSSpeaker\` (`config.json`, `state.json`, `log.txt`)
- 지우기: 트레이 → 종료, `exe` 지우기, 위 폴더 지우기, 시작 프로그램 폴더(`shell:startup`)의 `TTS 스피커` 바로가기 지우기.

## 만들기 (개발)

```powershell
.\pc\build.ps1      # E:\claude_보관\ttsspk_pc\dist\TTS스피커.exe
```

Python 3.13 + pystray · Pillow · comtypes(SAPI) · qrcode · cryptography · edge-tts, PyInstaller 로 exe 하나.
시험할 때만 쓰는 환경 변수: `TTSSPK_RELAY`(http://127.0.0.1:포트/ 만), `TTSSPK_HOME`, `TTSSPK_FAKE_AUDIO=1`, `TTSSPK_CTL_PORT`, `TTSSPK_STARTUP_DIR`, `TTSSPK_LINK_BASE`.
