# TTS 스피커

휴대폰에서 "밥 먹어라~" 하고 보내면, 집에 켜 둔 기기가 **딩동** 소리와 함께 소리 내어 읽어 줘요.

**주소:** https://s95722462-cell.github.io/ttsspeaker/

1. 집에 둘 기기(PC Edge · 안드로이드 Chrome)에서 열고 **이 기기를 스피커로 → ▶ 받기 시작**
2. 가족 휴대폰으로 스피커 화면의 **QR**을 찍으면 연결 (또는 6자리 코드)
3. 보내면 **보냄 → 🔊 말함 → 👍 확인** 으로 표시돼요

- 조용한 시간: 소리 없이 화면에만
- 메시지는 무료 공개 중계 서버 [ntfy.sh](https://ntfy.sh)를 거쳐요. 민감한 내용은 보내지 마세요.
- 보내는 화면의 **내 목소리**(👨 남자 · 👩 여자 · 이름)를 고르면 스피커가 그 목소리로 읽어요. 아빠·엄마는 저절로.
- 파일 하나(`index.html`)로 된 웹앱이에요.
- 늘 켜 두는 PC에는 브라우저 없이 트레이에서 도는 **PC 프로그램**도 있어요 → [`pc/`](pc/README.md)
